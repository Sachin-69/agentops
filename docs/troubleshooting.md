# Troubleshooting

## I forgot my password
Click **Forgot password?** on the login page and enter your email. We will send
a reset link that is valid for one hour. If you do not receive the email, check
your spam folder and make sure you entered the correct address.

## The page won't load
First, refresh the page. If that does not help, clear your browser cache and
cookies, then try again. If the problem persists, try a different browser or
disable browser extensions, which can interfere with the app.

## Exporting my data
You can export your data at any time from **Settings > Data > Export**. Exports
are generated as a ZIP file containing CSV and JSON files and are emailed to you
when ready, usually within a few minutes.

## Deleting my account
To permanently delete your account, go to **Settings > Account > Delete
Account**. This action is irreversible and removes all your data after a 14-day
grace period, during which you can still recover the account by logging in.
